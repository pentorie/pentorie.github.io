СИЛА СИБИРИ — АНИМИРОВАННЫЕ ЭКРАНЫ

1. Откройте index.html в Chrome или Edge.
2. Выберите нужный экран.
3. Горячие клавиши внутри каждого экрана:
   1–4      переключение между экранами
   F        полноэкранный режим
   Пробел   пауза / продолжение анимаций
   Двойной щелчок также включает полноэкранный режим.

Основной формат: 1920 × 1080 (16:9). Вёрстка адаптируется под другие размеры.
Все логотипы хранятся в исходном SVG-формате в assets/logos.
Для замены заглушки QR-кода измените блок .qr-placeholder в screen-4.html.
