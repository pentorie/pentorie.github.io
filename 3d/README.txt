3D-анимация «Сила Сибири»

Запуск:
1. Распакуйте архив.
2. Откройте index.html в Chrome, Edge, Firefox или Safari.
3. Файл sila-sibiri.svg должен оставаться рядом с index.html.

Быстрая настройка находится в начале CSS внутри index.html:
--logo-thickness: 16px;  половина общей толщины элемента
--turn-duration: 5.8s;   полная продолжительность цикла

Поворот выполняется от 0° до 360°, затем остаётся лицевой стороной до конца
паузы. При повторе 360° визуально совпадает с 0°, поэтому сброс не заметен.
