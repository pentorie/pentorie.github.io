Плоская анимация «Сила Сибири»

Запуск:
1. Распакуйте архив.
2. Откройте index.html в современном браузере.
3. Файл sila-sibiri.svg должен оставаться рядом с index.html.

Скорость регулируется в начале CSS внутри index.html:
--turn-duration: 5.8s;

Объёмные слои отсутствуют. Две совпадающие плоские стороны нужны только для
того, чтобы на обратной половине оборота логотип не отображался зеркально.
